# Tokenator — downloads

Tokenator is a macOS menu bar app that shows your limits and usage for
Claude Code, Codex and Grok Bot.

This repository only holds the installers. Get the latest one from
[Releases](../../releases/latest), open the DMG and follow
"How to open · Як відкрити.txt" inside.

`latest.json` tells installed copies of Tokenator that a new version is out.
